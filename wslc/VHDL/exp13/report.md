# 实验十三 蜂鸣器发音实验

[预习报告]{custom-style="副标题"}

## 一、实验目的
1. 了解蜂鸣器的工作原理及驱动方式。
2. 掌握利用 FPGA 产生不同频率方波以驱动蜂鸣器发出不同音调的方法。
3. 学习使用 VHDL 语言设计分频器和状态机来实现乐曲的自动播放。
4. 掌握数组（Array）在存储乐谱数据中的应用。

## 二、实验原理
### 1. 蜂鸣器发声原理
蜂鸣器是一种一体化结构的电子讯响器。本实验使用的是有源蜂鸣器（或无源蜂鸣器，视具体实验箱而定，但FPGA通常输出方波驱动）。通过改变输出方波的频率，可以使蜂鸣器发出不同音调的声音。
- **音调控制**：音调的高低取决于频率。例如，中央C（Do）的频率约为 261Hz，标准音A（La）的频率为 440Hz。
- **节拍控制**：音符持续的时间决定了节拍。通过计数器控制每个音符播放的时长。

### 2. 频率与分频计算
系统时钟为 24MHz。要产生频率为 $f$ 的方波，需要对系统时钟进行分频。
计数器计数上限 $N$ 计算公式为：
$$ N = \frac{f_{clk}}{2 \times f_{out}} $$
其中 $f_{clk} = 24,000,000$ Hz。
例如，产生 440Hz 的声音，计数器需要在 $24000000 / (2 \times 440) \approx 27272$ 次时钟周期后翻转一次输出电平。

## 三、实验内容
1. 计算不同音符（Do, Re, Mi...）对应的分频系数。
2. 编写 VHDL 程序，定义乐谱数组（包含音调和节拍信息）。
3. 设计分频逻辑产生音频信号，设计主控逻辑按序读取乐谱并控制播放时长。
4. 编译并下载程序，通过蜂鸣器播放“两只老虎”或“超级玛丽”等旋律。

## 四、实验所用设备
1. 实验室 PC（安装 Quartus II 13.1）
2. FPGA 实验箱（核心芯片：Cyclone III EP3C16Q240C8）
3. USB-Blaster 下载线

## 五、实验步骤
1. **工程建立**：在 Quartus II 中新建工程 `buzzer_play`。
2. **代码编写**：
    - 定义音符频率常量。
    - 建立乐谱数组（Melody Array）和节拍数组（Rhythm Array）。
    - 编写分频进程产生音频方波。
    - 编写主控进程控制乐谱播放进度。
3. **引脚分配**：将时钟、复位和蜂鸣器信号分配到对应引脚。
4. **编译下载**：编译工程并下载到 FPGA。
5. **验证**：按下复位键，聆听蜂鸣器是否播放预期的旋律。

## 一、实验步骤

### 1. 音符频率计算与常量定义
根据公式 $N = 12,000,000 / f$，计算了常用音符的分频计数值：
- Low C (Do): 261Hz $\rightarrow$ 45866
- Middle A (La): 440Hz $\rightarrow$ 27272
- High C (Do): 523Hz $\rightarrow$ 22944
并在 VHDL 代码的 Architecture 头部定义为常量。

### 2. 乐谱数据录入
本实验选择了“只因你太美”作为测试旋律（参考 `buzzer_play.vhd`），同时也准备了“超级玛丽”（`mario.vhd`）和“两只老虎”（`two_t.vhd`）作为备选。
乐谱通过两个数组实现：
- `melody`：存储每个音符对应的频率计数值。
- `durations`：存储每个音符的持续时间（节拍数）。

### 3. VHDL 代码设计
核心逻辑包含两个进程：
1.  **音调产生进程**：根据当前音符的计数值 `tone_target` 进行计数，当计数达到一半周期时翻转 `buzzer` 输出电平，从而产生对应频率的方波。
2.  **播放控制进程**：利用 `tempo_cnt` 控制节拍时间（基准约为 100ms）。每当一个节拍时间结束，根据 `durations` 数组判断当前音符是否播放完毕，若完毕则读取下一个音符的频率和节拍。

### 4. 引脚分配
根据实验箱硬件手册及 `buzzer_play.qsf` 文件：

| 信号名称 | 引脚号 | 说明 |
| :--- | :--- | :--- |
| clk | PIN_210 | 24MHz 系统时钟 |
| reset | PIN_151 | 复位按钮（高电平有效） |
| buzzer | PIN_174 | 蜂鸣器输出 |

### 5. 编译与下载
全编译工程，无报错后生成 `.sof` 文件。连接实验箱，通过 JTAG 接口下载程序。

## 二、实验数据及结果分析

### 1. 实验现象描述
- 下载程序后，蜂鸣器开始播放预设的旋律。
- 声音清晰，音调准确，能够辨识出是“只因你太美”的旋律片段。
- 节拍快慢适中，休止符（`NOTE_REST`）处理正确，音乐有停顿感。
- 按下复位按钮（PIN_151），音乐立即停止并重置到开头；松开按钮后，音乐重新开始播放。

### 2. 结果分析
- **音准分析**：由于 FPGA 时钟精度高（24MHz），分频产生的音频频率误差极小（<1%），人耳听感音准良好。
- **节奏分析**：通过 `tempo_cnt` 精确控制了每个音符的毫秒数，配合 `durations` 数组，实现了长短音的区分（如 8 分音符与 4 分音符），还原了乐曲的节奏感。
- **代码健壮性**：加入了 `NOTE_REST`（频率为 0）的处理逻辑，当遇到休止符时，强制 `buzzer` 输出低电平，避免了噪音或持续啸叫。

## 三、实验结论
1. 成功利用 FPGA 的 PWM/分频原理驱动蜂鸣器播放了完整的乐曲。
2. 验证了通过查找表（数组）方式存储和读取乐谱数据的可行性。
3. 掌握了数字系统中多任务协同工作的设计方法（一个进程产生音频，另一个进程控制播放进度）。
4. 实验达到了预期目的，不仅复现了简单的“两只老虎”，还成功播放了更复杂的流行歌曲旋律。

## 四、总结及心得体会
- **关键操作要点**：在计算分频系数时，要注意公式是 $f_{clk} / (2 \times f_{out})$ 还是 $f_{clk} / f_{out}$，取决于代码是在半周期翻转还是全周期清零。本实验采用半周期翻转，故分母需乘 2。
- **知识关联**：本次实验是计数器应用的一个有趣扩展，将枯燥的频率计算转化为可听的声音，直观地展示了频率与周期的关系。
- **问题与解决**：在调试初期，发现复位逻辑与硬件不符（代码写了低电平复位，但硬件按键产生正脉冲）。通过修改代码中的复位判断条件（`IF reset = '1'`），解决了复位异常的问题。
- **能力提升**：提升了对 VHDL 复杂数据类型（如数组）的应用能力，以及对状态机和时序控制的理解。

## 五、附录（实验源码）

### 1. buzzer_play.vhd (核心逻辑)
```vhdl
-- 音调产生进程
PROCESS(clk, reset)
BEGIN
    IF reset = '1' THEN
        tone_div_cnt <= 0;
        buzzer_reg   <= '0';
    ELSIF rising_edge(clk) THEN
        IF tone_target = NOTE_REST THEN
            buzzer_reg <= '0'; -- 休止符静音
        ELSE
            IF tone_div_cnt >= tone_target THEN
                tone_div_cnt <= 0;
                buzzer_reg   <= NOT buzzer_reg; -- 翻转电平
            ELSE
                tone_div_cnt <= tone_div_cnt + 1;
            END IF;
        END IF;
    END IF;
END PROCESS;
buzzer <= buzzer_reg;
```
