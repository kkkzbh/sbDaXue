## 4x4 键盘设计（exp14）

### 1. 目标与假设
- 目标：用 4x4 键盘完成 2x2 矩阵的录入与计算；配合数码管、蜂鸣器与 LED 状态提示。
- 假设：矩阵元素为整数（建议限定范围，见“数值范围与溢出”）。

---

### 2. 键位定义（基础版，保留 X 为无效键）

### 2.0 本仓库落地实现采用的映射（重要）
exp14 的 `key_scanner.vhd` 已按常见 4x4 键盘布局解码为如下 `key_val`：

```
┌────┬────┬────┬────┐
│ 1  │ 2  │ 3  │  A │
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │  B │
├────┼────┼────┼────┤
│ 7  │ 8  │ 9  │  C │
├────┼────┼────┼────┤
│  * │ 0  │  # │  D │
└────┴────┴────┴────┘
```

在 `matrix_calculator.vhd` 中，功能键采用：
- **normal**：A=MODE，B=+，C=*，D=BACK（切换编辑 A/B；在结果页返回编辑）
- **single**：A=T，B=POW，C=DET，D=EXIT，#=NOR
- **pow 子模式**：1~9 输入幂次，#=OK，D=EXIT

其余未用键视为无效键，触发错误提示。

#### 2.1 normal 模式键位（矩阵 A/B 的录入与运算）
```
┌────┬────┬────┬────┐
│MODE│  + │  * │BACK│
├────┼────┼────┼────┤
│ 7  │ 8  │ 9  │  X │
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │  X │
├────┼────┼────┼────┤
│ 1  │ 2  │ 3  │  X │
└────┴────┴────┴────┘
```
- MODE：进入/退出单矩阵操作模式（single matrix mode）。
- +：矩阵加（A+B）。
- *：矩阵乘（A×B）。
- BACK：返回上一个矩阵/取消当前操作（建议行为一致化）。
- 1~9：用于矩阵元素录入或切换选中元素（见“矩阵编辑规则”）。
- X：无效键，按下触发错误提示音效。

#### 2.2 single matrix mode 键位（单矩阵运算）
```
┌────┬────┬────┬────┐
│  T │ POW│ DET│ NOR│
├────┼────┼────┼────┤
│  X │  X │  X │  X │
├────┼────┼────┼────┤
│  X │  X │  X │  X │
├────┼────┼────┼────┤
│  X │  X │  X │EXIT│
└────┴────┴────┴────┘
```
- T：转置（结果替换当前矩阵）。
- POW：乘方（进入乘方子模式）。
- DET：行列式（不修改矩阵，结果在数码管显示）。
- NOR：模方（A^T * A，结果替换当前矩阵）。
- EXIT：退出单矩阵操作模式，回到 normal。
- X：无效键，按下触发错误提示音效。

#### 2.3 乘方子模式（pow）
```
┌────┬────┬────┬────┐
│  X │  X │  X │EXIT│
├────┼────┼────┼────┤
│ 7  │ 8  │ 9  │  X │
├────┼────┼────┼────┤
│ 4  │ 5  │ 6  │  X │
├────┼────┼────┼────┤
│ 1  │ 2  │ 3  │ OK │
└────┴────┴────┴────┘
```
- 1~9：输入幂次（建议 1~9）。
- OK：确认执行乘方。
- EXIT：退出乘方子模式（回到 single matrix mode）。

---

### 3. 矩阵编辑规则（建议明确）
**建议统一“选中元素 + 输入值”的规则：**
- 元素选择：用 7/8/4/5 对应 2x2 的四个位置  
  - 7 -> (1,1), 8 -> (1,2), 4 -> (2,1), 5 -> (2,2)
- 元素赋值：  
  - 1~9 作为直接输入值（单键覆盖）  
  - 若要多位数，可用“短按累加、长按清零”的方式扩展（可选）
- 当前选中元素可用 LED/数码管闪烁提示（推荐）。

> 如果你更倾向“数字键只负责输入”，则可改为：  
> - 9 作为“切换选中元素”  
> - 1~8 作为数值输入  
> 但要在文档中明确。

---

### 4. 状态与行为规范
- 计算完成：蜂鸣器短提示音（参考 exp13）。
- 错误输入（无效键/非法操作/溢出）：蜂鸣器错误音效 + 数码管显示“Err”。
- 行列式超出显示范围：数码管显示“Err”，并触发错误音效。
- 退出/取消行为统一：BACK/EXIT 都应清晰定义“返回到哪个状态”。

---

### 5. LED 指示建议
- 右侧 LED 条：
  - 1 个灯亮：normal 模式。
  - 全灯闪烁：single matrix mode。
  - 计算 A+B / A×B 时，亮 2 个灯（表示参与矩阵数）。
- 若有“当前选中矩阵 A/B”，建议用固定 LED 指示 A/B。

---

### 6. 可选优化（把 X 变为有效键）
如果希望操作更顺畅，可将 3 个 X 变成常用功能：
- X1：切换矩阵 A/B。
- X2：清零当前选中元素。
- X3：一键回到 normal。

这样能减少组合操作，提升可用性。

---

### 7. 需要补充的关键点（落地实现前必填）
- 元素位宽与范围（例如 `-9~9` 或 `0~9`）。
- 行列式计算公式与溢出界限。
- 多位数输入规则（是否支持，怎么输入）。
- BACK/EXIT 在不同模式的统一行为。
