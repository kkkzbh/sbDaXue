# 扩展式博弈实验结果分析

## 1. 实验配置概述
扩展式博弈实验选用经典的进入与威慑（Entry-Deterrence）场景，输入文件存放于 `tree_input/entry_game.json`。Alice 代表潜在进入者，Bob 则是既有垄断者。博弈树从 Alice 是否进入的抉择开始，如果她选择进入，Bob 随后在接受和惩罚之间作出回应；三种终局收益依次为进入后接受的 `[3, 1]`、进入后惩罚的 `[-1, -1]`，以及 Alice 直接退出时的 `[1, 0]`。

## 2. 运行产出

在 `exp2/` 目录执行 `python tree_demo.py entry_game` 后，终端会先列出每名参与者的完全策略集，再枚举全部四种策略组合并标出是否构成纯策略纳什均衡；本例中 `(Alice:进入, Bob:接受)` 与 `(Alice:退出, Bob:惩罚)` 两个组合满足均衡条件。程序同时生成博弈树图像 `tree_output/entry_game.png`，节点、行动与收益信息在图中清晰呈现。

## 3. 结果解读
实验揭示出两个纯策略纳什均衡：其一是 Alice 进入而 Bob 接受，此时双方收益 `[3, 1]` 达成帕累托优势；其二是 Alice 退出而 Bob 宣称惩罚，获得 `[1, 0]`。后者虽然在纳什定义下自洽，却建立在 Bob 的威慑威胁可被信任的前提之上，一旦进入真正发生，他反而更愿意接受以避免双方亏损，因此若应用子博弈完美均衡的标准，该组合将被剔除。收益比较也表明，为了阻止进入，既有厂商往往需要通过让渡部分利润来改变对手预期。

## 4. 模块验证
从实现角度看，模块能够完整构建每位参与者的策略空间，最佳响应检验准确区分两个均衡点，并确保图像输出与终端日志保持一致：节点顺序、行动标签和收益向量均在图中正确映射，这为进一步嵌入更复杂的均衡概念奠定了可靠基础。

## 5. 讨论与启示

进入与威慑博弈强调动态环境中可信承诺的关键性，也为后续研究提供了方向：若引入重复互动或信息不完美的设定，可以更加系统地讨论声誉与混合策略在威慑形成中的作用；与此同时，实现逆向归纳算法并在图中高亮子博弈完美均衡路径，将显著提升分析流程的自动化程度和解释力。
