# 策略式博弈设计说明书

## 1. 模块概览
- 目标：解析策略式（正规式）博弈描述，求解纯策略纳什均衡，并生成收益矩阵图像。
- 核心文件：`normal_form.py` 提供数据结构与算法；`matrix_demo.py` 负责命令行入口和批处理逻辑。
- 关键产物：控制台报告全部策略组合及均衡状态，`matrix_output/` 下的 PNG 收益矩阵。

## 2. 程序结构
### 2.1 数据模型
- `Strategy`：单个策略，包含 `key` 与展示用 `label`。
- `Player`：博弈参与者，维护策略列表。
- `NormalFormGame`：封装标题、参与者、收益张量与元数据，同时提供策略遍历与均衡计算函数。
- `PureEquilibrium`：用于记录纯策略纳什均衡的索引、策略标签与收益向量。

### 2.2 辅助方法
- `_pick(mapping, *candidates, default)`：用于兼容多语言字段名的通用取值器。
- `_setup_chinese_fonts()`：尝试注册文泉驿字体，保障图像中文展示。

## 3. 数据流与关键步骤
1. **输入解析**：
   - 支持传入 JSON 字符串、文件路径或字典对象。
   - `_validate_payoffs` 递归检验收益张量形状，确保与参与者策略数一致。
2. **策略枚举**：
   - `iter_strategy_profiles()` 通过 `itertools.product` 枚举策略组合，返回索引元组与收益向量。
3. **均衡判定**：
   - `pure_nash_equilibria()` 为每个参与者构造最佳响应表，再筛选出各方策略均为最佳响应的组合。
4. **矩阵绘制**：
   - `visualise_payoff_matrix()` 将收益向量写入单元格，使用黄色高亮纳什均衡，底部注明收益顺序。

## 4. 算法细节
- **复杂度**：主要瓶颈为策略组合枚举，时间复杂度 `O(Π|S_i|)`。
- **数值稳定性**：收益值统一转为 `float`，可处理整数与浮点输入；若需要比对浮点误差，可按需扩展容差。
- **边界条件**：
  - 少于两名参与者会触发 `ValueError`。
  - 任一参与者无策略或收益张量维度不匹配会在载入阶段报错。
  - 目前可视化仅支持两名参与者，但算法层面允许三人以上博弈的均衡判定。

- **核心实现**：纯策略纳什均衡检验依赖逐档比较最佳响应，以下节选展示如何缓存对手选择下的最优策略。

```python
def pure_nash_equilibria(self) -> list[PureEquilibrium]:
  profiles = list(product(*[range(len(p.strategies)) for p in self.players]))
  best_payoffs = [{} for _ in self.players]
  best_responses = [{} for _ in self.players]
  for profile in profiles:
    payoff_vector = self.payoff_at(profile)
    for player_idx, value in enumerate(payoff_vector):
      other_key = profile[:player_idx] + profile[player_idx + 1 :]
      current_best = best_payoffs[player_idx].get(other_key, float("-inf"))
      if value > current_best:
        best_payoffs[player_idx][other_key] = value
        best_responses[player_idx][other_key] = {profile[player_idx]}
      elif value == current_best:
        best_responses[player_idx][other_key].add(profile[player_idx])
```

## 5. 可视化设计
- 布局：顶部标题、中部表格、底部收益顺序说明。
- 尺寸：基础 `6×4`，随策略行列数线性扩展，避免文本拥挤。
- 表头：首行列设置淡蓝色背景，左上角显示“行玩家策略 / 列玩家策略”。
- 均衡高亮：使用浅黄色背景标记纯策略纳什均衡所在单元格。
- 字体：若系统存在文泉驿微米黑字体则自动启用；否则回退到默认 sans-serif。

## 6. 操作说明
### 6.1 基本运行
```bash
cd exp2/
python matrix_demo.py prisoners_dilemma
```
- 若未提供参数，将批量处理 `matrix_input/` 目录下的全部 JSON。
- 使用 `--show` 可弹出交互式窗口显示图像。

### 6.2 输入文件格式
```json
{
  "标题": "囚徒困境",
  "参与者": [
    {"编号": "row", "名称": "Alice", "策略": ["合作", "背叛"]},
    {"编号": "column", "名称": "Bob", "策略": ["合作", "背叛"]}
  ],
  "收益": [
    [[-1, -1], [-3, 0]],
    [[0, -3], [-2, -2]]
  ]
}
```
- 支持中文或英文字段；策略项可写成字符串或对象（含 `id`、`label` 等字段）。
- 收益数组的深度与长度必须与策略数完全一致，末端收益向量长度等于参与者数。

### 6.3 输出文件
- 图像保存在 `matrix_output/<输入文件名>.png`。
- 控制台会打印：
  - 每名参与者的策略列表；
  - 全部策略组合的收益与是否纳什均衡；
  - 纯策略纳什均衡的策略配置与收益。

### 6.4 常见问题排查
- **未找到输入**：确认 JSON 位于 `matrix_input/` 或提供完整路径。
- **收益维度报错**：检查嵌套列表是否与策略数相符，建议使用数组校验工具。
- **图像中文乱码**：在 Linux 安装文泉驿字体，或手动指定其他已知中文字体。
