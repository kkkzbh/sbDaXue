# 实验总结与心得体会

两类博弈的建模与可视化实验整体验证了架构设计的完整性：策略式模块以囚徒困境为代表，用统一的 JSON 规范将参与者、策略与收益张量串联起来，枚举纯策略组合并借由最佳响应缓存筛出纳什均衡，最终通过矩阵图形化呈现结果；扩展式模块则通过递归解析博弈树、构建完全策略空间并计算路径收益，展示了动态互动中威慑与承诺的博弈逻辑。两套流程在“载入 → 枚举 → 求解 → 可视化”这一主线下保持了一致的接口风格，也证明了抽象层次划分得当。

从实现经验来看，兼容中英文字段的 `_pick` 工具、对收益张量和节点结构的严格校验、以及自动部署中文字体等细节，大幅提升了脚本的鲁棒性与可移植性；同时也暴露出若干潜在提升空间，例如扩展式博弈的绘图暂未直接标注均衡路径，无法像矩阵图那样一眼捕捉结果，后续可考虑在可视化阶段引入逆向归纳或高亮标记。算法层面，当前仅覆盖纯策略纳什均衡计算，面对混合策略或子博弈完美均衡仍需额外模块支撑，这恰好构成下一轮迭代的自然方向。

综合两段实验可以体会到：统一的数据描述与模块化的求解流程，让我们能够快速替换博弈场景并复用计算组件；而实时生成的图像与日志输出，则为撰写报告和课堂展示提供了直观素材。今后若能在此基础上补充混合策略求解、逆向归纳标记、乃至网络化界面呈现，将进一步提升系统的分析力与可操作性，为更复杂的经济或战略问题打下良好基础。
