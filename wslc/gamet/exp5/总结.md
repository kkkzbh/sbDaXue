# 实验5：优点与缺点

## 优点
- 结构清晰：界面层（QML）/桥接层（GUI 控制器）/算法层（博弈求解）分离，易讲解、易维护。
- 计算完整：支持纯策略与混合策略纳什均衡，并能通过逆向归纳回贴第一阶段收益。
- 交互直观：参数实时调整、矩阵高亮展示均衡，演示效果好。
- 可扩展：报复等级、信念分布、均衡选择策略都可调，便于扩展实验场景。

## 缺点
- GUI 侧目前只展示纯策略均衡坐标，混合策略仅在终端文本中显示。
- 逆向归纳时对多重均衡采用“乐观/保守/平均”简化规则，未显式建模参与者的选择机制。
- 第一阶段调整矩阵在 GUI 侧重建，存在逻辑重复（后端未直接暴露调整矩阵）。
- 判定“警察成功”的规则偏宽松：只要存在某个均衡包含坦白即判成功，多均衡场景可能偏乐观。
