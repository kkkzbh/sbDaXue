# 实验5：动态囚徒困境与两阶段博弈模拟系统

## 1. 实验简介

本项目实现了一个基于**完全信息动态博弈**的模拟系统，重点分析“囚徒困境”在动态场景下的演化。

模型包含两个阶段：
1.  **第一阶段（坦白-沉默博弈）**：传统的囚徒困境，但玩家会考虑未来的期望收益。
2.  **第二阶段（报复-对抗博弈）**：如果第一阶段有人坦白，释放后可能面临黑社会或同伙的报复。

系统利用**逆向归纳法（Backward Induction）**，先求解第二阶段各报复等级下的纳什均衡，计算未来期望收益，再将其贴现回第一阶段，从而判断警察制定的“坦白从宽”政策是否有效。

## 3. 环境与安装

### 3.1 依赖环境
-   **操作系统**: Windows (WSL2) 或 Linux
-   **Python**: 3.8+ (推荐 3.12)
-   **Qt 库**: PySide6

### 3.2 安装步骤

1.  **激活虚拟环境** (假设位于 `../.venv`):
    ```bash
    source ../.venv/bin/activate
    ```

2.  **安装依赖**:
    ```bash
    pip install pyside6
    ```

### 3.3 WSL 特殊配置 (重要)
在 WSL 环境下运行 GUI 需要特殊配置（已封装在 `run_gui.sh` 中）：
-   使用 `xcb` 平台插件。
-   强制软件渲染 (`LIBGL_ALWAYS_SOFTWARE=1`) 以避免驱动兼容性问题。
-   **解决库冲突**: 自动识别 pip 安装的 `PySide6` 路径，并优先加载，避免与系统自带的 Qt 库冲突。

## 4. 运行方法

### 4.1 启动图形界面 (GUI) - 推荐

使用提供的脚本一键启动：

```bash
cd exp5
./run_gui.sh
```

**GUI 功能指南**:
-   **左侧控制面板**:
    -   **警察信念**: 调整警察对不同报复等级（轻微到严重）发生概率的预估。
    -   **环境设定**:
        -   `黑社会强度系数`: 调整报复造成的伤害倍率。
        -   `启用逆向规则`: 勾选后，"被出卖方"也会对"出卖方"进行报复。
        -   `均衡选择策略`: 当存在多个均衡时，选择 乐观(Max)/保守(Min)/平均(Avg) 收益。
    -   **刑期设定**: 调整第一阶段的基础刑期（坦白奖励、背叛惩罚等）。
    -   **自动寻找策略**: 点击按钮，系统会尝试自动调整参数以达成“坦白”均衡。
-   **右侧可视化面板**:
    -   **第一阶段矩阵**: 显示包含未来贴现值的最终收益矩阵。
    -   **第二阶段详情**: 展示 4 个不同报复等级下的子博弈纳什均衡。

### 4.2 启动命令行版本 (CLI)

```bash
python main.py
```
按提示输入参数，或选择预设的测试案例。

## 5. 算法与模型细节

1.  **纳什均衡求解**:
    -   **纯策略**: 遍历所有策略组合，寻找互为最优反应的点。
    -   **混合策略**: 当不存在纯策略均衡时，利用无差异原则求解概率 $p$ 和 $q$。

2.  **期望值计算**:
    -   $E = \sum (P(等级_i) \times V(等级_i均衡收益))$

3.  **结果判定**:
    -   **成功**: 第一阶段的均衡结果中，至少有一个罪犯选择“坦白”。
    -   **失败**: 均衡结果为 (沉默, 沉默)。

## 6. 常见问题 (Troubleshooting)

-   **报错 `ImportError: undefined symbol`**:
    -   这是由于系统 Qt 库与 Python 库冲突。**请务必使用 `./run_gui.sh` 启动**，不要直接运行 `python main_gui_.py`。
-   **界面无响应或全黑**:
    -   WSL 图形驱动问题，脚本中的 `LIBGL_ALWAYS_SOFTWARE=1` 通常能解决此问题。
-   **矩阵文字乱码**:
    -   已通过自适应网格布局修复，请确保代码已更新到最新版本。
