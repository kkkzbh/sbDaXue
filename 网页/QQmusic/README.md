# 音乐网页课程练习

在线访问：**https://music.kkkzbh.cn/**

这是大学期间制作的音乐网站界面练习，沿用原有页面、封面和歌单。它是独立的课程作品，与 QQ 音乐官方无关联；导航、会员、充值等区域为界面展示，不提供登录、支付或数据收集服务。

## 播放功能

- 11 首歌曲，点击歌曲封面播放或暂停；同一时间播放一首歌曲。
- 底部原生播放器支持暂停、进度拖动和音量调节。
- 提供上一首、下一首、播放全部；歌曲结束后继续播放下一首。
- 首次打开不自动播放，歌曲被选中后才加载音频。
- 歌曲区支持手机、平板和桌面宽度；页面其他区域保留原课程作业的界面布局。

页面使用浏览器原生音频解码，播放失败时会显示提示。

## 文件与素材

| 路径 | 用途 |
| --- | --- |
| `QQmusic.html` | 课程页面、11 首歌单与播放器控件 |
| `player.css` | 歌单布局及播放器样式 |
| `yongzhe.js` | 播放、暂停、切歌、连续播放和状态提示 |
| `Music/` | 11 个原始音频，涵盖 MP3、M4A、OGG、FLAC，完整归档在 GitHub |
| `Playback/dramaturgy.mp3` | 《拟剧论》的网页播放版，由原 FLAC 转换 |
| `imgQQmusic/` | 原课程页面使用的封面、图标和图片 |
| `build-site.py` | 检查资源并生成可发布的 `dist/` |

Cloudflare Pages 的单个静态资源上限为 25 MiB，因此《拟剧论》使用 MP3 播放版，原 FLAC 保留在仓库中。其余十首直接使用原始音频。构建脚本依据页面引用收集资源，检查引用是否存在及大小是否满足发布限制。

## 本地查看

在本目录执行：

```sh
python3 build-site.py
python3 -m http.server 8000 --directory dist
```

浏览器打开 `http://localhost:8000/`。无需安装前端依赖。

## 发布与更新

站点托管于 Cloudflare Pages，连接本仓库的 `main` 分支。构建设置：

| 配置 | 值 |
| --- | --- |
| 项目名 | `sbdaxue-music` |
| 框架预设 | None |
| 根目录 | `网页/QQmusic` |
| 构建命令 | `python3 build-site.py` |
| 输出目录 | `dist` |
| 自定义域名 | `music.kkkzbh.cn` |

推送更新到 `main` 后由 Cloudflare 自动构建发布。首页从 `QQmusic.html` 生成，音乐、图片、样式和脚本一起发布。`dist/` 为生成文件，不提交到仓库。

新增歌曲时把音频放进资源目录，在页面歌单中填写标题、作者、封面和音频路径，并运行构建检查。超过单文件大小限制的原始音频可在仓库中归档，再为网页生成合适大小的播放版。

歌曲和图片沿用原课程练习素材，各自权利归对应权利人；复用这些素材时需另行确认适用的授权。
