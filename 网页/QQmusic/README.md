# 音乐网页课程练习

在线访问：**https://music.kkkzbh.cn/**

这是大学期间制作的音乐网站界面练习，沿用原有页面、封面和歌单。它是独立的课程作品，与 QQ 音乐官方无关联；导航、会员、充值等区域为界面展示，不提供登录、支付或数据收集服务。

## 播放功能

- 11 个原始音频文件保存在 `Music/`，涵盖 MP3、M4A、OGG 和 FLAC。
- 点击歌曲封面播放或暂停；同一时间播放一首歌曲。
- 底部原生播放器支持暂停、进度拖动和音量调节。
- 提供上一首、下一首、播放全部；歌曲结束后继续播放下一首。
- 首次打开不自动播放，歌曲被选中后才加载音频。

页面使用浏览器原生音频解码，具体格式支持取决于浏览器。播放失败时会显示提示。

## 本地查看

在本目录启动静态文件服务，例如 `python3 -m http.server 8000`，然后访问 `http://localhost:8000/QQmusic.html`。

## 发布

GitHub Actions 工作流 `.github/workflows/music-pages.yml` 发布此目录到 GitHub Pages，并将 `QQmusic.html` 作为网站首页 `index.html`。音乐、封面和播放器脚本随站点一起发布。`music.kkkzbh.cn` 的 DNS CNAME 指向 `kkkzbh.github.io`。

更新本目录并推送到 `main` 后会自动部署，也可以手动触发工作流。`Music/` 是播放器所需资源，需与源码一并提交。

歌曲和图片沿用原课程练习素材，各自权利归对应权利人；复用这些素材时需另行确认适用的授权。
