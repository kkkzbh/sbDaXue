### （一）在教学管理JXGL数据库中进行如下操作：

#### 1、建立选课表SC2，表SC2上不用定义外码约束

```sql
CREATE TABLE SC2 (
    Sno CHAR(9),
    Cno CHAR(4),
    grade SMALLINT,
    PRIMARY KEY(Sno, Cno)
);
```

#### 2、往SC2中输入和SC表一样的数据

```sql
INSERT INTO SC2

```

#### 3、定义触发器update_sc，其功能是当学生表S中的学号发生变化时，自动更新选课表SC2中该学生选课记录中的学号

```sql
DELIMITER //
CREATE TRIGGER update_sc2 
AFTER UPDATE ON student 
FOR EACH ROW
BEGIN 
    IF OLD.Sno <> NEW.Sno THEN
        UPDATE SC2 
        SET Sno = NEW.Sno 
        WHERE SC2.Sno = OLD.Sno;
    END IF;
END //
DELIMITER ;
```

说明：在MySQL中，触发器可以使用OLD（旧数据）和NEW（新数据）引用来访问更新前后的数据。

#### 4、更新学生表student中201215121学生的学号为201215166，并用select语句观察SC2中的该生的学号是否自动更新了

由于原始表SC与student表之间存在外键约束（SC.Sno引用student.Sno），直接更新会导致外键约束冲突。在MySQL中，我们可以通过临时禁用外键约束检查来解决这个问题：

```sql
-- 临时禁用外键约束检查
SET FOREIGN_KEY_CHECKS = 0;

-- 更新学生表
UPDATE student
SET Sno = '201215166'
WHERE Sno = '201215121';

-- 更新SC表中的记录
UPDATE SC
SET Sno = '201215166'
WHERE Sno = '201215121';

-- 重新启用外键约束检查
SET FOREIGN_KEY_CHECKS = 1;

-- 查看SC2中的记录变化
SELECT * FROM SC2 WHERE Sno = '201215166';
```

#### 5、定义触发器uc，其功能是当学生表C中的课程号发生变化时，自动更新选课表SC2中的课程号

```sql
DELIMITER //
CREATE TRIGGER uc
AFTER UPDATE ON course
FOR EACH ROW
BEGIN
    IF OLD.Cno <> NEW.Cno THEN
        UPDATE SC2

```

#### 6、参照3步骤，试着写一下定义级联删除功能的触发器

#### 5、创建一个计算两个整数加减乘除的函数

```sql
DELIMITER //
CREATE FUNCTION computer(x INT, y INT, c CHAR(1)) 
RETURNS INT
DETERMINISTIC
BEGIN 
   DECLARE result INT;
   IF c = '+' THEN SET result = x + y;
   ELSEIF c = '-' THEN SET result = x - y;
   ELSEIF c = '*' THEN SET result = x * y;
   ELSEIF c = '/' THEN SET result = x / y;
   ELSE SET result = NULL;
   END IF;
   RETURN result;
END //
DELIMITER ;
```

#### 6、求7+15

```sql

```

#### 7、求37-15

```sql
SELECT computer(37, 15, '-') AS result;
```

#### 8、求3*15

```sql

```

#### 9、求103/15


## 二、总结及心得体会

在本次实验中，我学习了MySQL中的触发器和存储过程的创建与使用：

1. 触发器（Trigger）是一种特殊类型的存储过程，它在满足定义的条件时自动执行。在本实验中，我们创建了以下几种触发器：
   - 当学生学号更新时自动更新选课表中的学号
   - 当课程号更新时自动更新选课表中的课程号
   - 当删除学生记录时级联删除其选课记录

2. 存储过程（Stored Procedure）是一组为了完成特定功能的SQL语句集，经编译后存储在数据库中，用户通过指定存储过程的名字并给出参数来执行。本实验中创建了显示指定系别学生信息的存储过程。

3. 自定义函数（User-Defined Function）允许我们创建可重用的代码块，本实验中创建了一个可进行四则运算的函数。

4. 在实验过程中，我学习了如何处理外键约束问题。当需要更新主表中被从表引用的主键时，会产生外键约束冲突。MySQL提供了SET FOREIGN_KEY_CHECKS选项，可以临时禁用外键约束检查，这样就可以先更新主表，再更新从表，最后重新启用外键约束检查。这种方法在需要维护数据一致性的同时又需要更新数据的场景中非常有用。

通过本次实验，我深入理解了MySQL数据库中触发器、存储过程和自定义函数的作用和使用方法，以及如何处理外键约束相关的问题，这些知识对于构建和维护一个完整性良好的数据库系统非常重要。
